# Aircraft Explorer — Agent Guidelines

## Project Overview

Aircraft Explorer is a commercial aviation
discovery website built for Assignment 2 of
Design, Build, Ship.

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Static website architecture
- No database or backend
- No external runtime APIs

## Design Direction

The final website uses the Sky Minimal
design system.

Design principles:
- Clean visual hierarchy
- Generous but intentional whitespace
- Aviation-inspired blue accents
- Strong aircraft photography
- Accessible and responsive interfaces

## Project Requirements

- Three distinct mood boards
- 25–30 artifacts per mood board
- Three complete design systems
- Interactive Aircraft Explorer
- Responsive layouts at 390px and 1440px

## Development Workflow

1. Review the assignment requirements.
2. Implement changes incrementally.
3. Present results for human review.
4. Incorporate specific design feedback.
5. Test interactions and accessibility.
6. Verify the production build.

## Constraints

- Preserve the existing design system.
- Avoid unnecessary dependencies.
- Keep aircraft information accurate.
- Credit third-party photography.
- Do not perform Git or GitHub operations
  without explicit user permission.
